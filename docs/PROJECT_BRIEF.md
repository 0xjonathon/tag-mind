# TagMind 项目描述

## 一句话定位

TagMind 是创作者的本地素材理解与检索工作台：不修改原文件，通过 ASR、视觉模型、LLM 和语义索引，让用户用一句自然语言直接找到素材与对应时间点。

## 用户与问题

核心用户是短视频创作者、剪辑师和内容运营。传统文件检索只能匹配文件名，无法回答“嘉宾提到预算不足的那一段”或“适合片头的雨夜城市空镜”。创作者因此需要逐个打开、播放和拖动进度条。

## 核心价值

1. 从“按文件名找文件”升级为“按内容找片段”。
2. 保留原始 ASR/OCR 证据，LLM 整理结果可校对、可追溯。
3. 原文件只读，避免剪辑工程因改名或移动而媒体脱机。
4. AI 能力可插拔，支持自定义 OpenAI-compatible API 与本地服务。

## MVP 工作流

1. 用户拖入文件或整个文件夹。
2. 浏览器读取类型、时长、分辨率、缩略图和 SHA-256 指纹。
3. 音频/视频发送至用户配置的 ASR 端点，保留时间片段。
4. 图片与视频关键帧发送至视觉模型，提取客观画面描述和 OCR。
5. LLM 基于原始证据校对文字、生成摘要、实体、标签与剪辑维度。
6. 文本生成 Embedding；搜索时结合关键词与余弦相似度排序。
7. 用户预览素材、点击时间戳跳转，并导出 Markdown/CSV 场记单。

## 非目标

- MVP 不修改媒体元数据或原文件名。
- MVP 不做完整视频逐帧分析；仅分析代表关键帧。
- MVP 不承诺自动生成最终成片。
- MVP 不在服务端保存用户素材或 API Key。

## 成功标准

- 10–20 个混合素材可完整建立索引。
- 测试查询的正确内容进入前三条结果。
- 带时间戳结果可以从对应位置播放。
- 任一 AI 能力失败时，其他素材和本地索引仍可使用。
- 原始文件内容与修改时间不变。

## 路演演示

先展示一组 `IMG_`、`VID_` 命名的混乱素材，然后搜索“提到准点下班的高能口播”和“适合转场的雨夜城市空镜”。点击结果直接跳转时间点，最后导出场记单。核心表达是：过去靠文件名管理素材，现在 AI 能理解素材里面有什么。
