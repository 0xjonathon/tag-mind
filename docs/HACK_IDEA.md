# TagMind：一句话找到素材里的那一秒

我们想为视频创作者和剪辑团队做一个**不改文件名、会自己理解内容的 AI 素材搜索工具**。

真实痛点是：拍摄、采访和直播结束后，素材散落在大量视频、音频和图片中。为了找到一句台词、一个画面或某种情绪，创作者经常要逐个打开文件、来回拖动进度条，真正剪辑前就浪费数小时。

用户选择一个素材文件夹后，TagMind 以只读方式建立索引：转写音视频台词并保留时间戳，识别图片和视频画面，交给用户自选的 LLM 校对文本、生成摘要与标签，再把文件、内容和时间点建立映射。之后用户只需搜索“嘉宾提到预算不足的那一段”或“雨夜城市空镜”，就能直接找到对应素材并跳到那一秒。

## 现场演示

1. 拖入一组包含视频、音频和图片的真实素材；
2. 展示 AI 自动转写、画面理解、文本校对和标签生成；
3. 输入一句自然语言需求，返回匹配文件、内容证据和精确时间点；
4. 一键导出带文件名、台词、时间戳和标签的剪辑场记单。

## 24 小时范围

我们只做透一条核心链路：**选择文件夹 → AI 建立索引 → 一句话检索 → 定位素材/时间点 → 导出场记单**。不做素材管理大而全的功能，也不改动原始文件。

这个工具首先解决我们自己每天找素材的重复劳动；一条十分钟的视频，预计能减少 1～3 小时的翻找、听写和交接时间，让创作者把时间留给真正的创作，也让团队更接近准点下班。
