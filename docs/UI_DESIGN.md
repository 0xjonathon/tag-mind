# TagMind UI 设计说明

## 设计目标

界面采用“智能素材桌面”的视觉概念，与旧版黑底、暖灰和荧光绿的编辑部风格彻底分离。雾蓝作为画布，靛蓝代表主要操作与 AI 能力，青色代表处理完成和本地安全状态，珊瑚色只提示异常。半透明悬浮面板、柔和阴影和点阵背景共同营造一个轻盈、安静的个人素材空间。

## 信息架构

```text
悬浮顶部栏：品牌 / 演示数据 / 导出 / 当前 AI 服务
玻璃侧栏：智能筛选 / 媒体类型 / 内容分类 / Hook / 情绪 / 标签 / 重复素材
主区域：工作台摘要 / AI 素材记忆入口 / 自然语言问答式搜索 / 素材卡片
详情弹窗：深蓝媒体监看区 / 原始证据 / 时间片段 / LLM 整理结果 / 可编辑标签
AI 侧边抽屉：服务商卡片 / 自定义连接 / 四项模型路由 / 隐私说明
```

## 核心页面状态

### 空状态

以“不翻文件夹，直接问素材”为主标题，强调检索行为的变化；右侧使用悬浮记忆卡展示读取、听懂、看懂、整理四步流水线。主操作为选择文件夹，次操作为选择若干文件。

### 处理中

导入区域切换为单一进度状态，展示当前文件与当前步骤。失败不会中断整个批次。

### 已建立索引

显示自然语言搜索框和素材卡片。卡片必须展示分析来源：本地索引、ASR 原文、Vision AI、ASR + LLM 或 AI 降级，避免把启发式结果伪装为真实识别。

### 详情

左侧保留媒体播放与时间戳跳转；右侧严格区分“原始识别证据”和“AI 整理结果”。用户可以修改整理文字和标签，但不修改原文件。

## 交互原则

- 证据优先：原始 ASR、OCR 和关键帧描述始终可查看。
- 来源可见：卡片和详情展示分析来源及降级原因。
- 安全默认：密钥隐藏、原文件只读、语义能力按开关启用。
- 可降级：没有 API 或部分端点失败时仍能浏览、去重和关键词搜索。
- 键盘友好：输入框、按钮和原生媒体控件保留明确标签与焦点状态。

## 自定义 AI 设计

- 一级入口：顶部始终显示「自定义 AI」，并用状态点提示是否启用。
- 三种接入：OpenAI 官方预设、本地 Ollama、完全自定义 OpenAI-compatible 服务。
- 完全自定义：用户可设置显示名称、Base URL、API Key。
- 模型路由：文本整理、视觉理解、语音转写、Embedding 各自填写模型名与独立开关。
- 可验证：连接测试只请求当前文本模型，成功或失败就地反馈。
- 配置摘要：保存区展示当前服务名称和文本模型，避免连接错服务。

## 响应式策略

- 桌面端使用居中的宽幅工作台，显示玻璃筛选栏和多列素材网格。
- 小屏隐藏固定侧栏，保留搜索和内容主流程。
- AI 设置使用右侧抽屉；桌面宽度 610px，小屏占满，内部单列滚动。
